- Chunks: 3116. Body limit 3000 characters. The header is repeated on every part and is not counted in that limit. Bodies kept whole past that limit: 1. Longest body: 7317 characters.
- Embeddings: @cf/qwen/qwen3-embedding-0.6b, 1024 dimensions, cosine. Passages are embedded as documents. Questions use the query input with instruction: "Given a web search query, retrieve relevant passages that answer the query".
- Chunk text is stored in KV under the chunk id. Vector metadata has ids, title, url, kind, and chapter only.
- Vector ids are a 32-character sha256 prefix because ids are limited to 64 bytes. The logical chunk id remains `<entry id>#<part>`.
- Prompt v1. Answer model grok-4.7. Comparison model grok-4.6.
- XAI_API_KEY is unset. Answers are marked not called. The judge was skipped. The owner will hand-grade 40 later.
- Split seed 1729. Dev 100. Held out 445. Held out was scored once, after the threshold was frozen.
- Threshold 0.410. It was calibrated on closed-book dev similarities against the misuse set, so a question matching its own entry does not set the bar. Closed-book dev coverage at this threshold: 100.0%. Misuse prompts below it: 100.0%. The choice maximises that pair and keeps at least 90% of those dev questions covered when any threshold does.
- Boosts: page 0.08 (toggled), section 0.05, exact title 0.1, defines-term 0.06. Candidate pool 20, token budget 6000.
- Defines edges in this file run from chapter (184) to definition (121), section (29), theorem (19), proposition (6), remark (2), article (7). The file does not point a term at a box. A defines-term match boosts the target entry, the `to` side.
- Bank context: the current page is the question page, and the current section is the chapter on the question's `on` edge. Student context: the current page is the chapter page, so a section on that page can receive the page boost, and the expected entry's chapter receives the section boost.
- Closed retrieval drops the question, its worked answer, and overlapping entries from the top 50, then keeps 20. Questions with fewer than 20 closed candidates: 0.

Page boost does not change the bank chapter-hit rate. A question page holds the question and its worked answer, and closed-book removes both, so nothing on that page remains to boost.
