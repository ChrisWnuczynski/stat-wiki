## Lead context
A hidden layer lets a neural network form new features between its inputs and outputs, so a simple final decision can describe a nonlinear pattern in the original data.{{cite:bishop2006}} (Ch. 5, §5.1){{cite:rumelhart_hinton_williams1986}} (pp. 533–534)

## Motivating example
Consider two binary inputs that should produce one when exactly one input is on, and zero otherwise. The positive points $(1,0)$ and $(0,1)$ are the opposite corners of a square; the negative points $(0,0)$ and $(1,1)$ occupy the other diagonal. No single straight-line threshold can separate those two pairs. A hidden layer can report whether at least one input is on and whether both are on. The output then makes a linear decision from those two new features. The inherited XOR constructions and tables below give explicit integer-weight versions.{{cite:bishop2006}} (Ch. 5, §5.1, nonlinear hidden transformations){{cite:rumelhart_hinton_williams1986}} (pp. 533–534, learning hidden representations)

## Intuition
Each hidden unit measures a learned feature of the input. In a feed-forward layer, all hidden units receive the previous layer's activations; their outputs become the next layer's inputs. A nonlinear activation is the essential turn: if each layer only applies an affine map, multiplying and adding those maps produces another affine map, so depth alone cannot bend a decision boundary. With nonlinear units, a straight boundary in hidden coordinates can correspond to a curved or disconnected boundary in the original coordinates. This geometric picture explains why hidden representations can solve tasks a single threshold unit cannot, without promising that a training algorithm will find the needed weights.{{cite:bishop2006}} (Ch. 5, §5.1){{cite:rumelhart_hinton_williams1986}} (pp. 533–534)

## Definition
For input $x\in\mathbb R^p$, a layer of $l$ hidden units has preactivations $u_q=b_q+\sum_{j=1}^p w_{jq}x_j$ and activations $h_q=g(u_q)$, $q=1,\ldots,l$. An output layer with $m$ units then forms $z_k=c_k+\sum_{q=1}^l v_{qk}h_q$ and output $o_k=g_{\rm out}(z_k)$. The hidden units are called hidden because their values are computed inside the network rather than supplied as observed response variables. The inherited equations below use $w_{0q}$ and $w_{0k}$ for biases and the same symbol $g$ at both layers; the output activation can in general differ according to the prediction task.{{cite:bishop2006}} (Ch. 5, §5.1, feed-forward architecture){{cite:rumelhart_hinton_williams1986}} (p. 533, unit notation)

The number of weights and biases in one fully connected hidden layer is $(p+1)l+(l+1)m$. The first term counts $p$ incoming weights and a bias for each hidden unit; the second counts $l$ hidden inputs and a bias for each output. For $p=2$, $l=3$, and $m=1$, this is $3\times3+4=13$ parameters. This count describes an architecture, not the number of independent functions it can represent: relabelling hidden units can leave the network output exactly unchanged.{{cite:bishop2006}} (Ch. 5, §5.1, network weights and symmetries)

## Interpretation
Write the hidden vector as $h(x)$. The output layer applies a linear score to $h(x)$ before its final activation, so its coefficients describe directions in *learned feature space*. They do not generally give constant effects of the raw predictors. With a differentiable hidden activation and one output score $z=c+\sum_qv_qh_q(x)$, the local effect of input $x_j$ is $\partial z/\partial x_j=\sum_q v_q g'(u_q)w_{jq}$. It can change magnitude or even sign as $x$ changes because each derivative $g'(u_q)$ depends on location. A fitted hidden layer therefore replaces one fixed linear slope by a location-dependent combination of learned slopes.{{cite:bishop2006}} (Ch. 5, §§5.1–5.2)

The XOR construction has a particularly transparent interpretation: one hidden feature says “at least one input is on,” and another says “both are on.” This clarity is unusual. In a large fitted network, different sets of weights can compute the same function, so a hidden coordinate should not automatically receive a scientific name. What matters first is the network's mapping from inputs to outputs and whether it works on unseen cases.{{cite:rumelhart_hinton_williams1986}} (pp. 533–534, distributed representations){{cite:bishop2006}} (Ch. 5, §5.1)

## Properties
An output unit is linear in the *hidden activations* before its final activation, but the map from $x$ to $h$ is nonlinear when $g$ is nonlinear. The two inherited XOR tables demonstrate the distinction: the transformed four-point set becomes linearly separable, although the original set is not. A network can also learn a feature that is unnecessary. Copying an input into a hidden unit and feeding it onward may add no expressive power if a direct connection could do the same job. More hidden units offer more flexibility, but they also introduce more parameters to estimate and more opportunities to fit noise.{{cite:bishop2006}} (Ch. 5, §§5.1, 5.3){{cite:rumelhart_hinton_williams1986}} (pp. 533–534)

For smooth activations, the output changes differentiably with the weights and backpropagation applies the chain rule through the hidden layer. For hard threshold activations, the inherited XOR construction is exact on the four binary inputs, but its derivative is zero except at jumps. Thus an explicit representation and a gradient-based way to learn it are separate matters. Smooth sigmoids make learning derivatives available, while saturated sigmoid units can still pass very small gradients backward.{{cite:rumelhart_hinton_williams1986}} (pp. 533–534, differentiability and backpropagation){{cite:bishop2006}} (Ch. 5, §§5.1–5.2)

::: {.callout-note collapse="true" title="Proof"}
::: {.proof}
Suppose every activation is affine. If $h=Ax+a$ and $z=Bh+b$, then $z=B(Ax+a)+b=(BA)x+(Ba+b)$, another affine map. Induction collapses any number of such layers to one affine map. For XOR, a threshold classifier with score $a+bx_1+cx_2$ would need $a<0$, $a+b\geq0$, $a+c\geq0$, and $a+b+c<0$ for labels $0,1,1,0$. The middle two imply $2a+b+c\geq0$, while the first and last imply $2a+b+c<0$ by addition, a contradiction. The inequalities prove why a nonlinear representation is needed.{{cite:bishop2006}} (Ch. 5, §5.1, nonlinear hidden units)

The inherited two-unit OR-minus-AND construction provides existence. Define $h_3=1\{2x_1+2x_2-3\geq0\}$ and $h_4=1\{2x_1+2x_2-1\geq0\}$. Their values at $(0,0),(0,1),(1,0),(1,1)$ are respectively $(0,0),(0,1),(0,1),(1,1)$. The output $1\{-2h_3+2h_4-1\geq0\}$ is therefore $0,1,1,0$. There are $pl+l$ parameters to map $p$ inputs into $l$ hidden units, and $lm+m$ to map those units into $m$ outputs, giving $(p+1)l+(l+1)m$. Finally, permuting hidden-unit labels permutes columns of the first-layer weight matrix and corresponding rows of the second-layer matrix; each output sum is unchanged.{{cite:bishop2006}} (Ch. 5, §5.1, architecture and symmetry)

For differentiable $g$, $h_q=g(b_q+\sum_j w_{jq}x_j)$ has $\partial h_q/\partial x_j=g'(u_q)w_{jq}$ by the chain rule. Differentiating $z=c+\sum_qv_qh_q$ term by term proves $\partial z/\partial x_j=\sum_qv_qg'(u_q)w_{jq}$, the location-dependent slope described above.{{cite:bishop2006}} (Ch. 5, §5.2, chain rule through hidden units)

For the rectified example below, inspect four intervals. When $x\leq0$, all three hidden values are zero. When $0<x<1$, only $h_1=x$ is nonzero, so $o=x$. When $1\leq x<2$, $h_1=x$ and $h_2=x-1$, so $o=x-2(x-1)=2-x$. When $x\geq2$, all are active and $o=x-2(x-1)+(x-2)=0$. This proves the claimed peak and endpoint values.

## Statistical use
For classification, hidden layers can turn raw predictors into features that support a simple output decision. For regression, they can similarly represent a nonlinear mean function; the final activation should match the response scale. The chosen width and activation affect both expressiveness and estimation. In data analysis, use held-out observations or another honest validation procedure to assess whether extra flexibility improves prediction. An impressive boundary drawn through training points is not itself evidence that the learned representation generalizes.{{cite:bishop2006}} (Ch. 5, §§5.1, 5.3)

The representation is also not uniquely interpretable. Swapping two hidden units and their outgoing weights changes parameter labels but leaves predictions intact, so one hidden node is rarely an identifiable scientific variable by itself. A node that correlates with a named feature in a fitted sample may be useful for interpretation, but that interpretation needs more than its location in the architecture. The inherited tsetse example below illustrates a fitted nonlinear classification boundary; its application does not establish that every hidden unit has a one-to-one environmental meaning.{{cite:bishop2006}} (Ch. 5, §5.1, hidden-unit symmetry and mapping)

## Worked example
A smooth one-input network can create a central “on” region without a threshold gate. Let $g(z)=1/(1+e^{-z})$, $h_1=g\{10(x-0.25)\}$, $h_2=g\{10(x-0.75)\}$, and $o=g\{10(h_1-h_2-0.5)\}$. At $x=0$, the hidden activations are $h_1=0.075858$ and $h_2=0.000553$, giving output score $-4.246946$ and $o=0.014106$. At $x=0.5$, they are $0.924142$ and $0.075858$, giving score $3.482836$ and $o=0.970195$. The first hidden unit turns on near $0.25$ and the second near $0.75$; subtracting them detects the region between. A single sigmoid of an affine function of one input is monotone and cannot rise toward the center and fall again. This numeric network shows what the hidden representation adds, while the threshold XOR network below proves an exact discrete construction.{{cite:bishop2006}} (Ch. 5, §5.1, nonlinear hidden units)

**Your turn.** For the same network, calculate $h_1$, $h_2$ and $o$ at $x=1$. Explain why the result resembles the value at $x=0$.{{cite:bishop2006}} (Ch. 5, §5.1)

::: {.callout-tip collapse="true" title="Answer"}
At $x=1$, $h_1=g(7.5)=0.999447$ and $h_2=g(2.5)=0.924142$. Their difference is $0.075305$, giving score $10(0.075305-0.5)=-4.246946$ and output $o=0.014106$. The network responds weakly at either edge and strongly near the middle because the two shifted sigmoid features are separated most strongly there. The equal edge outputs follow from the symmetric placement of the two hidden transitions around $x=0.5$.{{cite:bishop2006}} (Ch. 5, §5.1)
:::

### Another feature map
An exact piecewise-linear feature can be built with three rectified hidden units. Set $h_1=\max(0,x)$, $h_2=\max(0,x-1)$, and $h_3=\max(0,x-2)$, then use the identity output $o=h_1-2h_2+h_3$. The output is zero for $x\leq0$, rises as $x$ between $0$ and $1$, falls as $2-x$ between $1$ and $2$, and is zero for $x\geq2$. At inputs $0,1,2,3$, its values are $0,1,0,0$. A single affine layer cannot make this central peak. This construction and the smooth sigmoid example serve different purposes: one yields an exact kinked response, the other a smooth central response.{{cite:bishop2006}} (Ch. 5, §5.1, nonlinear hidden feature maps)

The inherited tsetse classification example is a more complicated applied setting: climate and vegetation are inputs, and the predicted presence of flies has an irregular boundary. There the fitted hidden coordinates are useful because they permit a nonlinear map, not because each has a predetermined biological label. A real application still needs held-out assessment and checks of what the measurements represent.{{cite:bishop2006}} (Ch. 5, §§5.1, 5.3)

## Common misconceptions
A hidden layer is not a collection of unobserved random variables unless a probabilistic model explicitly makes it one; in an ordinary feed-forward network its activations are deterministic functions of inputs and weights. Extra depth does not automatically create nonlinear decision boundaries: affine activations collapse to one affine map. Solving XOR by hand does not show that backpropagation will learn those exact weights from a small sample. Finally, more hidden units are not inherently better; they can fit training noise or make optimization more difficult without helping predictions.{{cite:bishop2006}} (Ch. 5, §§5.1–5.3){{cite:rumelhart_hinton_williams1986}} (pp. 533–534)

## Assumptions and limits
The feed-forward equations assume a fixed layer order and specified activation functions. In the concrete XOR case, a single threshold fails because its four required inequalities contradict one another; the inherited two-unit hidden construction succeeds only because the hidden units are nonlinear. If every activation is affine, any proposed hidden width fails to repair XOR. If sigmoid hidden scores start deep in a tail, their derivatives are small and weight updates can be slow. If a very wide network memorizes a small training set, its near-zero training error can coexist with poor held-out accuracy. Permutation symmetry makes individual hidden weights non-identifiable without additional conventions.{{cite:bishop2006}} (Ch. 5, §§5.1–5.3){{cite:rumelhart_hinton_williams1986}} (pp. 533–534)

## History
The 1986 paper by Rumelhart, Hinton and Williams made learning internal representations central to its account of error backpropagation. Its diagrams and equations show input, hidden and output units with differentiable activations, and its examples explain why internal units can encode useful features. Bishop later presented these as feed-forward mappings within statistical pattern recognition. The inherited threshold XOR tables demonstrate representational capacity; the smooth training method and the architecture's statistical use developed alongside that geometric insight.{{cite:rumelhart_hinton_williams1986}} (pp. 533–535){{cite:bishop2006}} (Ch. 5, §5.1)
