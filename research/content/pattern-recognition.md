## Lead context

A digit on a cheque, a cell on a slide, and a customer who will or will not default are presented as vectors of features. The task is to assign the vector to a class, or to describe the kinds of vectors that occur when no class is given. Pattern recognition is that task. The name is shared with engineering and with machine learning. In statistics it means a probability model for the features, or a decision rule built from them, together with an error rate computed on observations that were not used to build the rule.{{cite:hastie_esl2009}} (p. 9, §2.2){{cite:james_islr2021}} (p. 26, §2.1.4)

## Definition

Pattern recognition is the construction of rules that assign observations to classes, or that describe the structure of observations when no class is given. In the statistical-learning vocabulary the inputs are called features, the word the pattern-recognition literature prefers for what regression calls predictors. The outputs are responses. A classifier is a function $G(x)$ taking values in a finite set of classes. It partitions the feature space into regions, one label to each region. The boundaries may be linear, in the sense that the set where two class scores are equal is a hyperplane, or they may be irregular.{{cite:hastie_esl2009}} (p. 9, §2.2; p. 101, §4.1)

When a response is observed, the problem is supervised: for each feature vector there is an associated label or measurement, and the fit relates the response to the features. When no label is observed, the problem is unsupervised. For every observation one sees a vector of measurements and no response. It is not possible to fit a regression, because there is nothing to predict. The analysis seeks relationships among the variables or among the observations. Clustering and principal-component summaries live on that side. The scope includes images, signals, and ordinary tabular measurements. It does not include every regression. A mean income predicted from age is not a pattern-recognition problem unless the scientific object is a class or a discovered grouping.{{cite:james_islr2021}} (p. 26, §2.1.4){{cite:hastie_esl2009}} (p. 9, §2.2)

## Statistical use

The reference rule is the [Bayes classifier](bayes-classifier.qmd), which assigns an observation to the class with the highest posterior probability given the features. When the class-conditional densities and the class proportions are correct, that rule has the lowest possible error rate among classifiers. [Linear discriminant analysis](linear-discriminant-analysis.qmd) and [quadratic discriminant analysis](quadratic-discriminant-analysis.qmd) approximate the rule by estimating those densities under normal features with a shared or a separate covariance. [Nearest neighbours](nearest-neighbours.qmd) estimates the class locally, without a global linear boundary. [Decision trees](decision-tree.qmd) and [random forests](random-forest.qmd) cut the feature space into rectangles. A [perceptron](perceptron.qmd) and a [kernel support vector machine](kernel-support-vector-machine.qmd) are further ways to state a boundary.{{cite:james_islr2021}} (p. 142, §4.4){{cite:hastie_esl2009}} (p. 101, §4.1)

Linear methods for classification model a discriminant function for each class, or a posterior probability, and assign the class with the largest value. If the discriminant or a monotone function of the posterior is linear in the features, the decision boundary is linear. Indicator regression, which fits a linear model to class indicators and classifies to the largest fit, is one member of that family. The boundary between two classes is then the hyperplane where the two fitted indicator means are equal.{{cite:hastie_esl2009}} (p. 101, §4.1)

Unsupervised companions are [principal component directions](principal-component-directions.qmd) and clustering, used when the goal is to describe the feature distribution rather than to name a class. Error rates for a classifier belong on data that were not used to build the rule. A training error can be driven toward zero by a flexible boundary and still say nothing about a new feature vector. [Cross-validation](cross-validation.qmd) is the usual check. Features are a choice. Two measurements that are rearrangements of each other can make a linear rule succeed or fail. The statistical problem starts after that choice and includes the uncertainty of the resulting error rate.{{cite:james_islr2021}} (p. 26, §2.1.4){{cite:hastie_esl2009}} (pp. 9 and 101)

## Common misconceptions

The Bayes rule is optimal for a known distribution. It is not what is computed from a finite sample. Plugging in estimated densities produces an approximation, and the approximation inherits every mistake in the density. Reporting the training accuracy as if it were that optimum is the mistake the held-out evaluation exists to prevent. A rule with a tiny training error and a large test error has fit the sample, not the pattern.{{cite:james_islr2021}} (p. 142, §4.4){{cite:hastie_esl2009}} (p. 101, §4.1)

A linear boundary is not a statement that the features are linearly related to each other. It is a statement about the set of points where two class scores tie. A curved cloud of features can still be separated by a hyperplane, and a pair of classes that wrap around each other cannot. Calling every classifier a neural network, or every cluster a discovered type, collapses distinctions the error rate was meant to keep separate. Unsupervised output has no response to get wrong, so a pleasing cluster plot is not a test-set accuracy.{{cite:james_islr2021}} (p. 26, §2.1.4)

## Connections

Pattern recognition is the classification face of [multivariate statistics](multivariate-statistics.qmd). It shares latent-variable models with [factor analysis](factor-analysis.qmd) when the features are treated as noisy views of a smaller set of causes. [Supervised learning](supervised-learning.qmd) is the labelled case, and [unsupervised learning](unsupervised-learning.qmd) is the unlabelled case. A [confusion matrix](confusion-matrix.qmd) is one way to display the errors once a held-out set exists. The same feature vectors appear in [medical statistics](medical-statistics.qmd) when the class is a diagnosis and the features are laboratory values. The statistical obligation in every one of those settings is the same: name the features, name the rule, and compute the error where the rule did not see the answer.{{cite:hastie_esl2009}} (pp. 9 and 101){{cite:james_islr2021}} (pp. 26 and 142)

## History

Discriminant methods and early neural rules grew up as ways to automate classification that a specialist could do by eye: species, letters, military targets. Fisher's iris data, with three species and four measurements, is the example statistical learning still uses to show a qualitative output on a finite set. The statistical-learning synthesis of recent decades treats those rules as one catalogue, with a common language of features, losses, and test error. Textbooks written for that synthesis cite the pattern-recognition literature as a parallel vocabulary rather than as a rival subject. The practical change was computational. A support-vector machine or a forest can be fit to feature vectors that no linear discriminant of the 1930s was asked to handle, and the evaluation standard is still a predictive error, not a significant coefficient.{{cite:hastie_esl2009}} (p. 9, §2.2; p. 101, §4.1){{cite:james_islr2021}} (p. 26, §2.1.4; p. 142, §4.4)
