## Motivating example
A program that labels an email from its word counts needs a rule that combines several signals into one decision. An artificial neuron first weights the signals, adds a bias, and then applies an activation rule. With a hard threshold it can say yes or no; with a sigmoid it can return a smooth score that can be adjusted by gradients. This simple unit matters because many such units can be connected so later layers respond to patterns that a single straight-line decision boundary cannot separate.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.1–6.3){{cite:rosenblatt1958}} (pp. 386–388, perceptron motivation)

## Intuition
The weighted sum $z=b+\mathbf w^{\mathsf T}\mathbf x$ determines which inputs push a unit toward activation. A positive weight increases $z$ as its input grows; a negative weight decreases it. The bias moves the threshold without changing the weights' direction. The activation function then decides how the score becomes output. A threshold turns the sign of $z$ into a bit, a logistic sigmoid maps it smoothly into $(0,1)$, and a rectified linear unit, or ReLU, returns the positive part of $z$. A unit's numerical output can be a hidden feature rather than a probability; its interpretation depends on the whole network and loss.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.1–6.3, output and hidden units)

## Definition
For inputs $x_1,\ldots,x_p$, weights $w_1,\ldots,w_p$ and bias $b$, define the net input $z=b+\sum_{j=1}^p w_jx_j$ and output $h=g(z)$. Writing $x_0=1$ and $w_0=b$ folds the bias into the same weighted-sum notation. The function $g$ is selected by the model: $g(z)=1\{z\ge0\}$ for the stated hard threshold, $g(z)=1/(1+e^{-z})$ for a logistic unit, or $g(z)=\max(0,z)$ for a ReLU. A sigmoid output can be read as a Bernoulli probability only when a probabilistic output model assigns it that role; a hidden sigmoid is simply an intermediate feature.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.2–6.3, sigmoid and rectified units){{cite:mcculloch_pitts1943}} (pp. 115–117, logical threshold model)

## Interpretation — Decision geometry and smoothness
The hard-threshold unit changes output on the hyperplane $b+\mathbf w^{\mathsf T}\mathbf x=0$. In two input dimensions that is a line; one unit can divide the plane into two half-planes. The threshold's derivative is zero away from the boundary and undefined on it, so its output offers no ordinary gradient for adjusting weights by chain rule. A logistic unit keeps the same ordering of net inputs but makes a gradual transition. Its derivative is $g(z)\{1-g(z)\}$, largest at $z=0$ with value $1/4$ and small at extreme net inputs. This is why a unit with a very confident sigmoid output may pass back only a small gradient.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.2.2–6.3, sigmoid units and gradients)

The AND example has weights $(1,1)$ and bias $-3/2$. The four binary input scores are $-3/2,-1/2,-1/2,1/2$, making only $(1,1)$ positive. Replacing the hard cut by the logistic function gives approximately $0.182,0.378,0.378,0.622$: the ordering survives, but the outputs are smooth. The sigmoid at $z=1/2$ is below a confident one because these weights were selected to get a correct hard decision, not to calibrate a probability.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.2–6.3, sigmoid output and hidden activation)

## Properties — Why layers change the model
Putting several units beside one another computes several features of the same input. Feeding those outputs into another unit composes their transformations. Nonlinear activations make this composition able to form boundaries that a single linear score cannot represent. If every layer used only an affine function, their composition would still be affine, no matter how many layers were stacked. The four corners of an XOR pattern are the simple counterexample: one straight boundary cannot put its two positive corners on one side and its two negative corners on the other, while a two-hidden-unit threshold network can form OR and NAND features and combine them.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §6.1, XOR example)

::: {.callout-note collapse="true" title="Proof"}
For the logistic function $g(z)=(1+e^{-z})^{-1}$, differentiation gives $g'(z)=e^{-z}/(1+e^{-z})^2=g(z)\{1-g(z)\}$. As a quadratic in $g\in(0,1)$ this is largest at $g=1/2$, hence at $z=0$, with maximum $1/4$. If $h(x)=Ax+a$ and $f(h)=Bh+b$ are affine layers, then $f(h(x))=BAx+(Ba+b)$, again affine. For XOR, suppose one threshold $1\{b+w_1x_1+w_2x_2\ge0\}$ labels $(0,0)$ and $(1,1)$ zero and $(1,0)$ and $(0,1)$ one. Then $b<0$, $b+w_1\ge0$ and $b+w_2\ge0$. Adding the last two inequalities yields $b+w_1+w_2\ge-b>0$, contradicting the required negative score at $(1,1)$. A nonlinear hidden layer can escape this single-hyperplane restriction.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §6.1, XOR and composition; §§6.2–6.3, sigmoid derivative)
:::

## Statistical use — From a unit to a fitted network
A logistic output unit with score $b+\mathbf w^{\mathsf T}\mathbf x$ has the same mathematical mean map as binary logistic regression. The difference is the surrounding architecture: in a network, the unit may receive learned hidden features rather than raw covariates. Training adjusts weights to reduce a chosen loss; backpropagation applies the chain rule through every differentiable layer. ReLU hidden units make active regions linear and inactive regions zero, which can simplify gradient calculations, but a unit stuck inactive on all training examples can receive no gradient through its ReLU. The output function, loss and target interpretation must therefore be specified together.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.2–6.3, output units, hidden units and ReLU gradients)

A single threshold or logistic unit based on raw two-dimensional inputs has a straight-line decision boundary, so it cannot classify XOR's alternating corners exactly. A logistic output cannot represent an exact probability of zero or one at finite weights; it approaches those values only in a limit. A ReLU at a negative net input is flat and may stop a gradient update for that training example. These are limits of representation, output range and optimization, respectively. Adding hidden units can address the first issue, but architecture alone does not guarantee a trained model will generalize from finite data.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.1–6.3, XOR, sigmoid and ReLU)

## Worked example
Let $\mathbf x=(2,1)$, weights $\mathbf w=(0.5,-1)$ and bias $b=0.25$. The net input is $z=0.25+0.5(2)-1(1)=0.25$. A hard threshold returns $1$, ReLU returns $0.25$, and a logistic unit returns $g(0.25)\approx0.562177$ with derivative $g(0.25)\{1-g(0.25)\}\approx0.246134$. If the first input changes to $0$ while the second stays $1$, then $z=-0.75$: the threshold and ReLU return $0$, while the logistic output is about $0.320821$. The same weights thus define three different output rules; only the score and boundary are shared.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.2–6.3, activation forms)

**Your turn.** Use weights $(1,-2)$ and bias $0.5$. For input $(3,1)$, compute the net input, threshold output, ReLU output, logistic output and logistic derivative. What is the ReLU output for input $(0,1)$?

::: {.callout-tip collapse="true" title="Answer"}
At $(3,1)$ the net input is $0.5+3-2=1.5$. The threshold output is $1$, ReLU returns $1.5$, and the logistic output is $g(1.5)\approx0.817574$ with derivative about $0.149146$. At $(0,1)$ the net input is $0.5-2=-1.5$, so ReLU returns $0$. The first input change crosses the ReLU's zero boundary; the derivative for an active ReLU is $1$, while it is $0$ in the negative region.
:::

## Common misconceptions
A unit's output is not automatically a probability: a hidden activation is usually a feature, and ReLU is unbounded above. A bias is not an additional observed predictor; its constant input is a mathematical device for shifting the boundary. A smooth sigmoid does not make a one-unit decision boundary nonlinear in the original inputs when classification uses a fixed output threshold. More layers also do not add nonlinear capacity if every activation is linear. Finally, the threshold's zero derivative makes direct gradient training difficult even though its decision rule is easy to compute.{{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.1–6.3)

## History
McCulloch and Pitts in 1943 described networks of all-or-none threshold elements as a logical calculus of neural activity. Rosenblatt's 1958 perceptron developed a trainable pattern-recognition model from that tradition. Modern artificial neurons also use smooth or rectified activations so gradient methods can fit many connected units; their mathematical role is a computational building block, not a literal model of every biological detail of a nerve cell.{{cite:mcculloch_pitts1943}} (pp. 115–117, logical threshold description){{cite:rosenblatt1958}} (pp. 386–390, perceptron proposal){{cite:goodfellow_deep_learning2016_ch6}} (Ch. 6, §§6.1–6.3)
