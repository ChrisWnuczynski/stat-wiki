## Motivating example
A sensor measures a concentration that can arise from either of two manufacturing processes. Each process may produce several clusters because it runs at different temperatures. Fitting one bell curve per process can smooth away those clusters. A density classifier instead asks which process assigns the larger local density to the observed concentration, after allowing for how common the processes are. Kernel estimates supply flexible class densities without declaring how many clusters a process has.{{cite:zhang_d2l2023}} (§11.2, Attention Pooling by Similarity)

## Intuition — Local evidence and class frequency
A kernel places a smooth bump around each training observation. The sum of the bumps estimates where a class tends to put its measurements. Dividing by the number of observations in the class turns that sum into a density; multiplying by the class prior then combines local evidence with prevalence. With empirical priors $\widehat\pi_g=n_g/n$ and a common kernel bandwidth, these two factors cancel the class sample size:
$$\widehat\pi_g\widehat f_g(x)=\frac1n\sum_{i:y_i=g}K_H(x-x_i).$$
Thus a common-bandwidth classifier can also be interpreted as a weighted vote, with nearby observations receiving larger weights. Normalising all class scores gives posterior probability estimates. This is the same normalization principle used for kernel classification with one-hot class labels.{{cite:zhang_d2l2023}} (§11.2, Regression and Classification)

The density-estimation kernel and a positive semidefinite kernel used in a support vector machine serve different mathematical roles. Here the kernel must integrate to one after its bandwidth scaling, because each class score comes from a probability density. A Gaussian function can serve in either construction, but that shared shape does not make the procedures interchangeable.{{cite:downey2014_thinkstats2}} (§6.2, Kernel density estimation)

## Properties — Probabilities, costs and bandwidths
For positive total score, Bayes' formula gives
$$\widehat P(Y=g\mid x)=\frac{\pi_g\widehat f_g(x)}{\sum_k\pi_k\widehat f_k(x)}.$$
Choosing the largest posterior minimizes conditional zero–one loss. Indeed, predicting $g$ has conditional error probability $1-\widehat P(Y=g\mid x)$, so maximizing the posterior minimizes that error. With loss $L(a,g)$ for choosing action $a$ when the true class is $g$, choose the action minimizing $\sum_g L(a,g)\widehat P(Y=g\mid x)$ instead. A rare but costly error can therefore change the decision even when the density estimates stay fixed.{{cite:holmes_huber2019_msmb}} (§12.5, Objective functions)

The estimates integrate to one: substitute $v=H_g^{-1/2}(x-x_i)$ in each bump, so the Jacobian $|H_g|^{1/2}$ cancels its scale factor, then average the resulting unit integrals. This justifies comparing densities whose bandwidths differ. Omitting the scale factor would reward a wider bump merely for covering a larger region. Bandwidth controls smoothing; a small value emphasizes nearby measurements, while a large value blends modes together.{{cite:downey2014_thinkstats2}} (§6.2)

For a fixed query and a common Gaussian bandwidth $h\to\infty$, $h\widehat f_g(x)\to\varphi(0)$, hence the estimated posterior tends to the prior. This is a pointwise limit. Equal priors need not produce an exact tie at any finite bandwidth. At $h\to0$, a query different from all observations has densities tending to zero, so numerical underflow is a practical issue; logarithms and stable score normalization help. Neither limit selects a statistically useful bandwidth by itself.{{cite:zhang_d2l2023}} (§11.2, Adapting Attention Pooling)

## Worked example — Reading the density ratio
For the two samples $\{0,1\}$ and $\{4,5\}$ with unit Gaussian bandwidth, the densities at $x=3$ are $0.0292114$ and $0.1479808$. Their ratio is about $5.0659$ in favour of class 2. Equal priors give posterior probability $0.83514$ for class 2. If process 1 accounts for $90\%$ of production, its score is $0.9(0.0292114)=0.0262903$, exceeding $0.1(0.1479808)=0.0147981$; the prediction changes to class 1. Local proximity and overall prevalence answer different parts of the question.{{cite:holmes_huber2019_msmb}} (§12.3, Linear discrimination, prior probabilities)

**Your turn.** At the symmetry point $x=2.5$, use priors $\pi_1=0.3$ and $\pi_2=0.7$. Find the posterior probabilities and the zero–one-loss decision.

::: {.callout-tip collapse="true" title="Answer"}
The class densities are equal, so they cancel from the posterior ratio. The posterior probabilities are $0.3$ and $0.7$, and the decision is class 2.
:::

## Statistical use — Reading a score as a vote
With a common bandwidth and empirical class proportions, $\widehat\pi_g\widehat f_g(x)$ equals $n^{-1}$ times the sum of the kernel bumps from class $g$. The class with the larger sum wins under zero–one loss. At $x=3$ in the worked samples the class-2 density is about $5.0659$ times the class-1 density, and equal priors give posterior probability $0.83514$ for class 2. Replacing the empirical prior by a deployment prior of $0.9$ for class 1 reverses the decision, because $0.9\times0.0292114$ exceeds $0.1\times0.1479808$. The cancellation of $n_g$ is a special case of the empirical prior. A deployment prior that differs from $n_g/n$ must be written back into the score.{{cite:zhang_d2l2023}} (§11.2, Regression and Classification){{cite:holmes_huber2019_msmb}} (§12.3, Linear discrimination, prior probabilities)

A cost-sensitive rule keeps the same posterior and changes the comparison. If a false assignment to class 1 costs $c$ times a false assignment to class 2, the conditional expected costs are proportional to $c\,\widehat P(Y=2\mid x)$ and $\widehat P(Y=1\mid x)$. Class 1 is preferred when its posterior exceeds $c/(1+c)$, with a tie on the boundary. For $c=2$ the threshold is $2/3$. In the worked example the equal-prior posterior $0.83514$ clears that threshold, while a posterior of exactly $2/3$ is a tie under this loss. The density estimates can stay fixed while the action changes, because the loss, not the kernel, sets the threshold.{{cite:holmes_huber2019_msmb}} (§12.5, Objective functions)

## Common misconceptions
A Gaussian bump used as a density kernel integrates to one after the bandwidth scaling. A Gaussian kernel in a support vector machine is a positive semidefinite similarity and need not integrate to one. Both formulas can contain $\exp(-\|x-z\|^2/(2h^2))$. The density classifier then multiplies by a class prior and compares classes. The support vector machine uses the similarities as inner products in a margin problem. Sharing the Gaussian shape does not make a bandwidth chosen for one problem into a penalty chosen for the other.{{cite:downey2014_thinkstats2}} (§6.2, Kernel density estimation)

The bandwidth limits describe the estimate, not a selected operating point. As a common Gaussian bandwidth tends to infinity, each class density flattens and the posterior tends to the prior at a fixed query. As the bandwidth tends to zero, a query that matches no training point has densities tending to zero together, and a numerical comparison of underflows is unstable. A useful bandwidth sits between those limits and has to be chosen by a criterion that matches the prediction target. Cross-validation of that choice uses only the training portion of each split. A bandwidth tuned on the same points that are later called a test set answers a question about that reuse.{{cite:zhang_d2l2023}} (§11.2, Adapting Attention Pooling){{cite:holmes_huber2019_msmb}} (§§12.4, 12.6, overfitting and dimensionality)

## Connections — The Bayes rule these estimates are imitating
If the class densities $f_g$ and the priors $\pi_g$ were known, the conditional error of predicting class $g$ would be $1-P(Y=g\mid x)$, and the smallest conditional error would come from the largest posterior. The kernel rule replaces each $f_g$ by $\widehat f_g$ and, unless a deployment prior is supplied, replaces $\pi_g$ by $n_g/n$. The resulting action minimizes the plug-in estimate of conditional zero–one loss. It minimizes the true conditional risk when those plugs are correct, which is a property of the population rule, not a property of every finite training sample. With several classes the same arithmetic applies: the displayed posterior denominator sums over every class, and omitting a class changes the remaining probabilities.{{cite:holmes_huber2019_msmb}} (§12.5, Objective functions)

The integral check justifies comparing densities on a common scale. For each training point the change of variables $v=H_g^{-1/2}(x-x_i)$ has Jacobian $|H_g|^{1/2}$, which cancels the factor in front of the bump, and the standard kernel then integrates to one. An implementation that drops $|H_g|^{-1/2}$ while letting one class use a wider matrix gives that class a larger unnormalized score for a purely algebraic reason. Bandwidths may differ by class when the scale factor is kept. They should differ when the classes really are smoother or rougher than one another, and that choice is part of the fitted procedure.{{cite:downey2014_thinkstats2}} (§6.2)

## Assumptions and limits
Training and test observations must be comparable on the measured coordinates. Rescaling one coordinate changes distances unless its bandwidth changes too. A full bandwidth matrix can describe directional smoothing, but estimating many directions requires data. Dimension makes local neighborhoods sparse; this is a statistical limitation rather than a universal bound of six predictors. Bandwidth and feature choices must be made within training folds if cross-validation is to estimate predictive performance fairly. A query far from every training point in a class is a place where the kernel density is small for every moderate bandwidth. The classifier then leans on the prior and on whichever class still has a bump nearby. That behaviour is visible in the scores and is a reason to inspect the fitted densities at the queries that matter, rather than only the training error.{{cite:holmes_huber2019_msmb}} (§§12.4, 12.6, overfitting and dimensionality)
