## Lead context
A calculation needs the observations gathered in one place, with a row for each unit and a column for each variable. That organised collection is a dataset. {{cite:abs_glossary2023}} (Glossary, “Dataset”) {{cite:dodge2008}} (p. 150)

## Motivating example
An agronomist has weighed 40 plots and recorded the fertiliser each plot received. Until those weights and labels sit in one table, there is nothing to plot and nothing to average. The table is the dataset. A sentence that says "yields were higher on the fertilised plots" is a claim about the dataset, not a substitute for it. {{cite:abs_glossary2023}} (Glossary, “Dataset”) {{cite:dodge2008}} (p. 150)

## Intuition
A dataset is a completed form. Each row answers "which unit", and each column answers "which fact about that unit". A frequency table, a mean, and a fitted line are views of the dataset. They can be rebuilt from it. The dataset cannot be rebuilt from the mean alone. {{cite:abs_glossary2023}} (Glossary, “Descriptive (or summary) statistics”) {{cite:dodge2008}} (p. 150)

## Definition
A dataset is a complete collection of the observations that an analysis will use. {{cite:abs_glossary2023}} (Glossary, “Dataset”) The observations are the recorded values of the variables under study, and they are quantitative or qualitative with those variables. {{cite:dodge2008}} (p. 150) {{cite:abs_glossary2023}} (Glossary, “Data”) The usual organisation is a two-dimensional table. {{cite:dodge2008}} (p. 150)

## Properties
The size of a dataset has two parts: the number of units and the number of variables. Five units and three variables give fifteen cells, some of which may be blank. A blank is part of the dataset's structure. Filling it with zero changes the dataset. {{cite:abs_glossary2023}} (Glossary, “Observation”) {{cite:abs_glossary2023}} (Glossary, “Data unit”)

Two analysts who drop different rows are no longer using the same dataset, even if they started from the same file. The claim has to name which rows remain. {{cite:dodge2008}} (p. 151) {{cite:abs_glossary2023}} (Glossary, “Dataset”)

## Statistical use
Description, estimation, and testing all take a dataset as input. Description reduces it to frequencies, averages, and plots. Estimation and testing add a model and produce a statement about a population. The dataset itself stays the record of what was observed. {{cite:dodge2008}} (p. 151) {{cite:abs_glossary2023}} (Glossary, “Descriptive (or summary) statistics”) {{cite:abs_glossary2023}} (Glossary, “Inferential statistics”)

## Worked example
A dataset of household sizes is 2, 4, 3, 2, 5. There are 5 observations. The value 2 appears twice, so its absolute frequency is 2 and its relative frequency is 2/5 = 0.4. The mean is (2+4+3+2+5)/5 = 16/5 = 3.2. {{cite:dodge2008}} (p. 208) {{cite:abs_glossary2023}} (Glossary, “Mean”) {{cite:abs_glossary2023}} (Glossary, “Relative frequency”)

**Your turn.** The household of size 5 is removed from the dataset. What are the new number of observations, the relative frequency of 2, and the mean?

::: {.callout-tip collapse="true" title="Answer"}
Four observations remain: 2, 4, 3, 2. The value 2 still appears twice, so its relative frequency is 2/4 = 1/2. The mean is (2+4+3+2)/4 = 11/4 = 2.75.
:::

## Common misconceptions
A dataset is not a model, and it is not the population. It is the observations in hand. Publishing only a chart does not publish the dataset. Readers who cannot see the observations cannot tell whether a point was dropped. {{cite:abs_glossary2023}} (Glossary, “Dataset”) {{cite:abs_glossary2023}} (Glossary, “Population”)

## Assumptions and limits
Completeness is relative to a stated list of variables and units. A dataset can be complete for the variables that were measured and silent on a variable that was never recorded. No later model invents that missing column from the ones that exist. {{cite:dodge2008}} (p. 150) {{cite:nist_glossary2002}} (Glossary, “model”)

## Connections
The rows are units from a [population](population.qmd) or a [sample](sample.qmd). The columns are [variables](variable.qmd). Counts of a column are a summary of the dataset, and a [parameter](parameter.qmd) is a feature of the population the table is used to study. {{cite:dodge2008}} (p. 353) {{cite:abs_glossary2023}} (Glossary, “Variable (data item)”)

## History
Organising records into tables is older than the mathematical theory that now reads them. What changed is the insistence that a numerical claim name the observations it used and the larger collection it is about. {{cite:dodge2008}} (p. 518) {{cite:abs_glossary2023}} (Glossary, “Dataset”)
