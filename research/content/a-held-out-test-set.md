## Lead context
An independent set of cases gives a prediction rule its first honest check against outcomes that did not help build it.{{cite:cawley_talbot2010}} (pp. 2079–2081, model selection and evaluation){{cite:cawley_talbot2010}} (§§2, 5.3, pp. 2080–2082, 2100–2103)

## Motivating example
A classifier can sort its training cases almost perfectly by memorizing them. Its apparent training error may be zero, yet the same rule can fail badly on new people. If 120 previously unseen cases are set aside before fitting and the finalized classifier makes 18 mistakes on them, the test error is $18/120=0.15$. Those 18 observations tell us about a *particular trained rule* under the sampling conditions that produced the test set. They do not erase the sampling uncertainty in that estimate, nor do they evaluate a different rule chosen after seeing the 18 errors.{{cite:efron1983}} (§1, p. 316, future-error target){{cite:cawley_talbot2010}} (pp. 2079–2081, selection bias)

## Intuition
Training makes a rule dependent on its data: even a modest modelling choice can favor the peculiarities of the cases it saw. Holding out labels and predictors together prevents the rule from responding to those peculiarities in the test cases. This separation works only if all fitting decisions are made without consulting them. Scaling, selecting predictors, choosing a threshold, comparing architectures, and deciding when to stop training are all fitting decisions when their outcomes influence the final rule. Using a test score to choose among twenty candidates turns that set into a validation set and makes the selected score optimistic on average.{{cite:cawley_talbot2010}} (pp. 2079–2081; §5.3, selection protocols){{cite:cawley_talbot2010}} (§§2, 5.3, pp. 2080–2082, 2100–2103)

## Definition
Partition labelled observations into training data and a held-out test sample before model development. Fit a complete prediction rule $\hat f_T$ using only the training side, including any allowed validation or cross-validation inside that side. For loss $Q(y,\hat f_T(x))$, the test estimate is the average $\hat R_{\rm test}=n_{\rm test}^{-1}\sum_{i\in\mathrm{test}}Q(y_i,\hat f_T(x_i))$. With zero–one loss, $Q$ is one for a wrong class and zero otherwise, so the estimate is the fraction misclassified. The formulas below use $\eta$ for the trained classifier and also display class-specific error rates. A class-specific rate has no denominator if that class has no test cases.{{cite:efron1983}} (§1, p. 316, future-error target){{cite:cawley_talbot2010}} (§§2, 5.3, pp. 2080–2082, 2100–2103)

The target is conditional on the fitted rule and on the test population: $R(\hat f_T)=\Pr\{\hat f_T(X)\ne Y\mid T\}$ for classification when a future $(X,Y)$ is drawn from that population. Averaging over possible training samples defines a different target, the expected performance of the *training procedure*. The test sample estimates the former conditional risk for the observed fit; repeated random splits or outer cross-validation address variability across fitted rules. If the rule is refitted on training *and* test data after evaluation, it is a new rule whose error was not independently measured by the old test score.{{cite:efron1983}} (§1, p. 316, future-error target){{cite:cawley_talbot2010}} (pp. 2080–2081, algorithm and evaluation distinctions)

## Properties
Conditional on a fixed trained classifier and independent identically distributed test cases from its target population, each test error indicator is Bernoulli with probability $p=R(\hat f_T)$. Thus the number of errors is binomial, $\mathbb E(\hat R_{\rm test}\mid T)=p$, and $\operatorname{Var}(\hat R_{\rm test}\mid T)=p(1-p)/n_{\rm test}$. The familiar standard error estimate is $\sqrt{\hat p(1-\hat p)/n_{\rm test}}$. It describes test-sample variability for that rule, not the variation caused by training on another sample. The calculation of 18 errors in 120 cases uses the corresponding normal approximation and shows why a small independent test set can still be imprecise.{{cite:dodge2008}} (pp. 44–46, Binomial distribution and normal approximation)

The partition creates a trade-off: more training data may improve the fitted rule, while more test data narrows the error estimate. No universal split fraction is best. The number of test observations should be chosen with the error rate or class-specific failures of interest in mind; rare classes can receive too few examples even when the overall test set seems large. The approximate half-width calculation illustrates the square-root scaling. If a deployment population differs from the sampled test population, an exactly computed test error estimates performance in the wrong population.{{cite:cawley_talbot2010}} (pp. 2079–2081, performance evaluation){{cite:cawley_talbot2010}} (§§2, 5.3, pp. 2080–2082, 2100–2103)

::: {.callout-note collapse="true" title="Proof"}
::: {.proof}
Condition on the training data $T$ and fix $\hat f_T$. If test pairs $(X_i,Y_i)$ are independent draws from the target distribution, the error indicators $E_i=1\{\hat f_T(X_i)\ne Y_i\}$ are independent Bernoulli variables with common mean $p$. Therefore $K=\sum_iE_i\sim\operatorname{Binomial}(n_{\rm test},p)$, $\hat p=K/n_{\rm test}$ has conditional mean $p$ and conditional variance $p(1-p)/n_{\rm test}$. If $0<p<1$, the Bernoulli central limit theorem gives $(\hat p-p)/\sqrt{p(1-p)/n_{\rm test}}$ approximately standard normal for large test sets; substituting $\hat p$ yields the approximate $1.96$-standard-error interval. Small counts or probabilities near zero or one weaken that approximation.{{cite:dodge2008}} (pp. 44–46, Binomial distribution and normal approximation)

For a class $g$ with $n_g>0$ test members, divide its number of misclassifications by $n_g$. Conditional on those class memberships and on the trained rule, its expectation is the class-conditional misclassification probability when the within-class cases are independent draws. Its precision is governed by $n_g$, not by the entire test size. The training variability remains because conditioning fixed $T$; by the law of total variance, $\operatorname{Var}(\hat R_{\rm test})=\mathbb E\{p_T(1-p_T)/n_{\rm test}\}+\operatorname{Var}(p_T)$ when the split samples are independent. A conditional binomial interval addresses the first component only.{{cite:cawley_talbot2010}} (pp. 2079–2081, variation in assessment)
:::
:::

## Statistical use
Separate development from evaluation. Reserve the test cases before any data-driven preprocessing or feature selection. Fit preprocessing on the training side, apply the learned transformation to validation and test cases, use training or validation only to choose hyperparameters, then freeze the full procedure before its single test evaluation. Report the test size, metric, class distribution and interval or other uncertainty summary. If the test outcome changes what you fit, another untouched sample is needed for a fresh independent assessment.{{cite:cawley_talbot2010}} (§§2, 5.3, pp. 2080–2082, 2100–2103){{cite:cawley_talbot2010}} (§5.3, evaluation protocol)

The holdout must follow the intended deployment unit. For repeated records from one person, putting one visit in training and another in test can test recognition of the same person rather than prediction for a new person. Hold people together when new-person performance is the target. For forecasting, a random split can let future observations help predict earlier ones; train on earlier periods and evaluate later periods instead. In either setting, an independent *row* is not necessarily an independent *unit*. A representative test set is also necessary: a hospital model tested only at the hospital where it was built may not estimate error at a second hospital.{{cite:cawley_talbot2010}} (§§2, 5.3, pp. 2080–2082, 2100–2103)

## Worked example
A fixed binary classifier is evaluated on 100 independent test cases: 20 truly positive and 80 truly negative. It misses 5 positives and falsely labels 8 negatives as positive. Its total error is $(5+8)/100=0.13$. The false-negative rate is $5/20=0.25$ and the false-positive rate is $8/80=0.10$; the overall 13% error hides the worse performance on positive cases. Treating the 13 error indicators as independent Bernoulli trials for this fitted rule gives estimated standard error $\sqrt{0.13(0.87)/100}=0.03363$ and approximate 95% interval $0.13\pm1.96(0.03363)=(0.064,0.196)$. That interval is deliberately approximate and conditional on the fitted rule and sampling population.{{cite:dodge2008}} (pp. 44–46, Binomial distribution and normal approximation)

**Your turn.** Another fixed classifier is tested on 150 new cases: 30 positive and 120 negative. It misses 6 positives and falsely marks 12 negatives positive. Compute the total error, each class-specific error rate, the estimated binomial standard error, and an approximate 95% interval for total error.{{cite:dodge2008}} (pp. 44–46, Binomial distribution and normal approximation)

::: {.callout-tip collapse="true" title="Answer"}
There are $6+12=18$ errors, giving total error $18/150=0.12$. The false-negative rate is $6/30=0.20$ and the false-positive rate is $12/120=0.10$. The estimated standard error is $\sqrt{0.12(0.88)/150}=0.02653$, so the approximate 95% interval is $0.12\pm1.96(0.02653)=(0.068,0.172)$. The total rate and class rates answer different questions; with only 30 positive cases, the false-negative estimate is much less precise than the total error estimate.{{cite:dodge2008}} (pp. 44–46, Binomial distribution and normal approximation)
:::

## Common misconceptions
“Held out” does not mean merely absent from the optimizer's final fit: using the test cases to select features or a threshold has already let them shape the rule. A test error is not the error of a future refit on all available data, because that refit is a different fitted rule. A narrow overall error interval does not ensure precise assessment of a rare class, whose denominator can be much smaller. Finally, a random row split is not a valid independence device when the prediction target is a new person, place or future period and records share a group or time structure.{{cite:cawley_talbot2010}} (§§2, 5.3, pp. 2080–2082, 2100–2103){{cite:cawley_talbot2010}} (pp. 2080–2081, selection bias)

## Assumptions and limits
The exact binomial calculation assumes a fixed classifier, independent test outcomes and one common error probability under the target population. With 20 test cases and zero observed errors, the naive standard-error plug-in is zero, but the rule's true error need not be zero; a better binomial interval or a larger test sample is needed. If ten test rows come from each of ten patients, treating 100 rows as 100 independent patients can make the reported interval far too narrow. If a rare class contributes only two test cases, its estimated error can be only $0$, $0.5$ or $1$, regardless of the overall sample size. Changes in case mix or measurement after deployment also limit what the old test estimates.{{cite:dodge2008}} (pp. 44–46, Binomial distribution and normal approximation){{cite:cawley_talbot2010}} (§§2, 5.3, pp. 2080–2082, 2100–2103)

## History
Efron's 1983 study framed the task as estimating the error of a prediction rule built from data for future classification. The separate selection-and-assessment problem became more prominent as many models and hyperparameters could be tried on finite validation samples. Cawley and Talbot's 2010 analysis showed how tuning an evaluation criterion can overfit it and argued for assessing the full selection procedure with an independent outer evaluation. The held-out test set is the simplest instance of keeping that final evaluation separate.{{cite:efron1983}} (§1, p. 316, future-error target){{cite:cawley_talbot2010}} (pp. 2079–2081; §5.3)
